# 🛡️ FRAUD LAB — Cyber Fraud Awareness Trainer & Live Shield

FRAUD LAB ek interactive, 100% frontend-only cybersecurity awareness web application hai[cite: 6]. Yeh users ko online frauds, social engineering tactics, fake legal notices aur phishing messages ko pehchanne aur unse bachne ki training deta hai[cite: 6].

---

## 🌟 Key Features

1. **Interactive 10-Scenario Training**
   - Phishing, OTP Fraud, QR/UPI traps, Social Engineering, aur Malware jaise 10 real-world scenarios par practice karein.
   - Har decision par instant detailed feedback aur explanation milti hai.

2. **Legal-Looking Scams Guide**
   - 15 common official-looking fraud patterns (jaise Digital Arrest, Fake Court Summons, Fake Police Verification, KYC Block) ki deep explanation.

3. **Live Shield (Message Risk Analyzer)**
   - Suspicious SMS, email, link ya payment request ko paste karke risk score aur safety guidance check karein[cite: 6].
   - **100% Client-Side Engine:** Poora risk analysis aapke browser me locally execute hota hai[cite: 6].

4. **Call Safety Preview**
   - Unknown calls ke liye interactive simulated safety warning preview[cite: 6].

5. **Personalized Completion Certificate**
   - Training complete karne par user ke naam aur completion date ke sath download/print-ready certificate generate hota hai.

6. **Emergency Incident Response Guide (India)**
   - Cyber fraud hone par immediate action steps (National Helpline 1930 aur Cyber Crime Reporting Portal details)[cite: 6].

---

## 🛠️ Tech Stack

- **Frontend:** Pure HTML5, CSS3, Modern JavaScript (ES6+)[cite: 6]
- **Risk Analysis Engine:** Built-in Local Client-Side JS Rule Engine[cite: 6]
- **Backend/Server:** NONE (No Node.js, Express, or API keys required)[cite: 6]

---

## 🚀 How to Run (Quick Setup)

Kisi bhi local server, Node.js ya terminal commands ki zaroorat nahi hai[cite: 6]!

### Option 1: Direct Browser Launch
1. Is repository ko clone ya ZIP download karke extract karein.
2. Direct `index.html` file par double-click karein aur apne kisi bhi web browser (Chrome, Edge, Firefox, Brave) me open karein.

### Option 2: Live Server (VS Code)
1. Repository ko VS Code me open karein.
2. **Live Server** extension install karein.
3. `index.html` par right-click karke **"Open with Live Server"** select karein.
